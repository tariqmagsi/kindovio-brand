# Kindovio brand

The Kindovio logo: a house with a heart at its door, and the Kindovio wordmark (Plus Jakarta Sans Bold, outlined) with the dots of the i's in the heart's coral.

| File | Use |
|---|---|
| `logo/kindovio-logo.svg` / `.png` | Horizontal logo on light backgrounds |
| `logo/kindovio-logo-on-dark.svg` / `.png` | Horizontal logo on dark backgrounds |
| `logo/kindovio-mark.svg`, `kindovio-mark-512.png` | The mark alone (app icon tile) |
| `logo/kindovio-mark-mono.svg`, `-mono-white.svg` | One-colour mark |
| `email/kindovio-logo-email-dark.png` | The logo in Kindovio's account emails (served from here, so every inbox can load it) |

Colours: deep green `#123C31` (tile `#2F7058` → `#103A2F`), cream `#FFF8EC`, coral `#E0644A` (heart `#F59B7D` → `#E0644A`).

Please don't rename or move the email image: sent emails link to it.
